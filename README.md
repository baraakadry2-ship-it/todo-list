# 📋 Mission Tracker (Todo List)

A modern and responsive Todo-List / Missions Tracker application built with React JS. This app helps users organize their daily tasks and track their progress with a clean and intuitive UI.

## ✨ Features
- ➕ Add new missions with a title and description.
- ✅ Mark missions as completed (with a visual indicator).
- ✏️ Edit existing missions.
- 🗑️ Delete missions.
- 🔍 Filter missions by status: All, Completed, or Uncompleted.

## 🛠️ Tech Stack
- **Frontend:** React JS
- **State Management:** React Hooks (useState, useEffect)
- **Styling:** CSS (or Tailwind CSS, if you used it)
- **Icons:** React Icons (if you used it)
